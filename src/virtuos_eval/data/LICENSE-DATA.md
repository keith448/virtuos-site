# Data licence

The corpus data bundled in this package (`data/v0.1-draft.jsonl`) is licensed
under **Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA
4.0)**, https://creativecommons.org/licenses/by-sa/4.0/.

The Python code is licensed under Apache-2.0.

The entries are AI-drafted summaries of public-domain and openly licensed
sources. Every entry records its source, licence and provenance. The dataset is
a draft: it carries no human labels and no verified translations, and it should
be cited as a draft, not as a finished standard.
