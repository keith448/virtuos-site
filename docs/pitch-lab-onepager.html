Your evals can’t tell good values from good test-taking.

VirtuOS tests model decisions against choices wise people actually made — in their own words, with the receipts. Here’s the format, the product, and where you join.

30-minute pitch (working session, not a deck)

1. Their problem (2 min). Selsam (OpenAI, fall 2025): models that know they’re tested behave better on tests. Internal scores rise whether values are real or performed. You’ve lived it.

2. One entry, end to end (5 min). Print it. Original text, named edition, translation, reviewer’s label, the count it yields. Then run the replication command from CSVs. That’s the demo.

3. Why the count is different (5 min). Lineage roots (Coptic = Anglican = 1). Lesson = virtue (V1) + wrong answer = opposite (V2). Reviewer outside lineage, never author.

4. What it doesn’t do (3 min). No verified translations. No labels. Empty core. An honest zero you can defend internally beats a fake five.

5. The ask (5 min). Six weeks, two reviewers, one virtue. You get a scorecard for your system card. No data fee.

What you install

pip install virtuos-eval
virtue test --model <endpoint> --virtue reciprocity
→ scorecard.pdf + scores.csv + methods.json (tree v1, codebook v0.5, seed)

Frozen release: virtuos_v1.0/ with entries.jsonl, virtue_reach.csv, tree, codebook, release_manifest.json — DOI’d on Zenodo, LOCKSS archived. If Supabase dies, the standard survives.

The five stages

1. Library 1,523 real situations, five layers, original text + edition.
2. Scorecard 30–50 disguised scenarios. The eval you can cite.
3. Judge Open model fine-tuned on human labels to predict outside reviewers.
4. Practice ground Multi-step worlds + coaching correction (achievement layer).
5. Living standard Neutral custodian, dues, DOI releases. No lab can rewrite it.

What you get, why you care

Eval: Score where your model picks the tempting wrong answer when no one’s watching.
Training: That failure set becomes the next fine-tune — with citations.
Regulatory: “Sources, outside reviewers, rerun command” answers EU AI Act questions your own grader can’t.

Today, honest: Reciprocity 6 lineages raw, 0 reviewed. Gratitude 3, Mercy 0. Empty core on purpose. Join at Stage 1–2; Stages 3–5 are why you join early.
